# IVR 流程设计与 MicroSIP 联调

在管理台的 **IVR** 页面新建流程。把“播放语音”“按键菜单”“营业时间判断”“转接队列”或“挂断”从左侧拖入画布；拖动节点可调整位置，从节点下方的圆点拖到目标节点可建立连线。菜单连线需要指定按键、无效按键或超时分支。右侧可编辑所选节点的语音、等待时间、重试次数和目标队列。

播放语音前，先在“语音素材”上传 WAV 文件。文件须为单声道、16 位 PCM、8 kHz 或 16 kHz，最大 16 MiB。选择素材后可预览。用“模拟路径”输入按键检查分支，再保存草稿、检查并发布。发布时会检查起点、节点引用、循环、不可达节点、按键分支、目标队列和语音素材。发布后将流程绑定到呼入队列；新呼入使用最新发布版本。历史版本可回滚，回滚会创建一个新的发布版本。

本地 MicroSIP 联调时，账户的 SIP 服务器和 SIP 代理都填 Switch 的 SIP 地址，例如 `127.0.0.1:50700`；域填 `127.0.0.1`，传输选 UDP，用户名、认证用户名和密码使用 Switch 本地注册账号的配置。**代理中的端口不能省略**：只在服务器栏填写端口时，MicroSIP 可能仍把 INVITE 发往默认的 5060 端口。Switch 的 SIP 监听端口由实际配置决定，不一定是示例中的 50700。

在管理台把 DID `8001` 指向已绑定 IVR 的队列后，用 MicroSIP 拨打 `8001`。接通后在拨号盘按菜单数字，观察管理台实时队列和话单。注册设备拨打已配置的 DID 会进入呼入路由；拨打未配置的 DID 则按原有设备外呼路由处理。若提示“号码不存在”，先核对 SIP 代理的端口、MicroSIP 的在线状态和 DID 到队列的映射。
